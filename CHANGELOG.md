# Changelog

## 0.1.0-beta - 2026-10-09

Initial public beta.

### Added

- VRChat-style radial menu preview.
- Full NDMF menu capture using the manual avatar-processing path.
- Modular Avatar menu support, including dynamically generated menu content.
- Avatar Pose Library (APL) menu visibility in the final preview.
- Editable generated menu copy and source snapshot.
- Rename, icon editing, submenu creation, deletion, and reordering.
- Drag-and-drop reordering and moving items into submenus.
- Cross-menu move controls.
- Automatic `More` pagination for menus over 8 controls.
- Duplicate generated-`More` filtering.
- Preservation of Modular Avatar build-time parameter/value semantics.
- Incremental synchronization for newly added NDMF menu items.
- Cleanup of temporary avatars created by NDMF manual processing.

### Known limitations

- Beta compatibility; unusual NDMF plugins may need dedicated support.
- Primarily Chinese editor UI.
