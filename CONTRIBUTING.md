# Contributing

Bug reports and compatibility findings are welcome.

When reporting a problem, please include:

- Unity version
- VRChat SDK version
- NDMF version
- Modular Avatar version
- Relevant plugin name/version (for example APL)
- The first red Unity Console error and stack trace
- A screenshot of the organizer preview and the actual Gesture Manager menu when they differ

Please avoid uploading paid avatar assets or third-party copyrighted packages to issues.
