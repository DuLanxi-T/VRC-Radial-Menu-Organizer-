# VRC Radial Menu Organizer

A visual VRChat expression-menu organizer for Unity 2022.3, designed for avatars that use **NDMF**, **Modular Avatar**, and menu-generating plugins such as **Avatar Pose Library (APL)**.

> Status: **Beta / experimental**. Back up your avatar project before using it.

## What it does

- Reads the avatar's **fully built NDMF expression menu**, not only the raw `VRCExpressionsMenu` asset.
- Shows the result as a VRChat-style **radial menu preview**.
- Supports menus generated by:
  - Modular Avatar
  - Avatar Pose Library (APL)
  - Other NDMF-based menu generators when they are present in the final processed menu
- Reorder menu items.
- Drag items into submenus/folders.
- Rename items and change icons.
- Create and delete submenus.
- Preserve Modular Avatar's real build-time parameter/value semantics.
- Avoid duplicate auto-generated `More` pagination entries.
- Synchronize newly added NDMF menu content without resetting the layout you already organized.
- Uses an editable generated copy instead of directly modifying the original menu assets.

## Requirements

- Unity **2022.3.x**
- VRChat SDK - Avatars
- NDMF
- Modular Avatar

Optional but supported in the final NDMF preview:

- Avatar Pose Library (APL)
- Other NDMF-based avatar tools that add expression-menu entries

## Installation

This beta currently ships as a single C# file.

1. Download `VRCMenuOrganizerCN.cs` from this repository.
2. Put it anywhere under your Unity project's `Assets/` folder.
3. Wait for Unity to finish compiling.
4. Open:

   `Tools -> VRChat -> 菜单整理器（最终R菜单版）`

Do **not** keep multiple older copies of the script in the same project, or Unity will report duplicate class/type errors.

## Basic workflow

1. Select your avatar's `VRC Avatar Descriptor`.
2. Click **① 读取完整 NDMF 菜单（含 APL）并创建安全副本**.
3. Edit the radial-menu preview.
4. Reorder items with the controls or by drag-and-drop.
5. Drag an item onto a submenu to move it inside that folder.
6. Click **② 启用最终菜单覆盖** when the layout is ready.
7. Test with Gesture Manager before uploading to VRChat.

If you add a new outfit, menu installer, APL content, or another NDMF menu source later, use:

**③ 同步新添加的 NDMF 菜单**

Newly detected content is placed into an `新增内容` submenu so your existing layout is not reset.

## Why the tool runs NDMF for preview

Many modern VRChat avatar tools do not store their final menu as a normal menu asset in the scene. They generate or modify it during the NDMF build process.

This organizer uses NDMF's manual avatar-processing path to obtain the processed expression menu, copies that menu into editable assets, and cleans up the temporary processed avatar afterward. This is what allows generated APL and Modular Avatar menu entries to appear in the preview.

## Important notes

- The editor preview is generated from a processed avatar copy. The original avatar is not intentionally baked or replaced.
- The tool keeps a source snapshot so build-time Modular Avatar parameters and values can be matched back to the organized layout.
- VRChat menus support a maximum of 8 user controls per menu. The organizer can create `More` pagination where needed.
- Always test the final result before publishing an avatar.

## Current limitations

- This is an early beta and has mainly been tested against the author's current VRChat/NDMF/Modular Avatar setup.
- Plugins that modify menus after the organizer's final build pass may require explicit compatibility work.
- A plugin with unusual dynamically generated controls may need additional matching logic.
- The UI is currently primarily Chinese.
